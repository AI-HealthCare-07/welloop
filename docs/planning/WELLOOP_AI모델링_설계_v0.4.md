## 1. 팀 결정 기록 (2026-11-27)

### 1.1 입력 방식

| 항목 | 결정 |
|---|---|
| 입력 경로 | 직접 입력 또는 검진 결과지 사진(PDF 포함) |
| 확인 화면 | **필수.** 추출한 수치를 사용자가 확인·수정한 뒤에만 모델에 넣는다 |
| 결과지에 LDL이 없을 때 | A 분기(검진 안내) |
| 총콜레스테롤·HDL | **수집하지 않는다** (민감정보 최소화) |
| 결과지 원본 | 수치 추출 후 저장하지 않는다 |

총콜레스테롤과 HDL을 받지 않으므로 Friedewald 식(`LDL ≈ 총콜레스테롤 − HDL − TG/5`)을 이용한 **인식 오류 자동 감지와 LDL 계산 보완은 하지 않는다.** 사용자 확인 화면이 유일한 오류 방지 장치다.

### 1.2 중성지방(TG) 처리

TG는 수치를 저장하지 않고 상태 세 가지로만 관리한다.

| TG 상태 | 처리 |
|---|---|
| 400 미만 | 모델 적용 |
| 400 이상 | **모델 미적용**, 진료 상담 안내 |
| 미확인 | 모델 적용, 확인 화면에서 TG 입력 권장 |

근거와 한계는 다음과 같다.

- **모델 1 학습 코호트 2,059명 중 TG 400 이상은 0명이다(최댓값 395).** 모델이 본 적 없는 범위라 적용 타당성이 검증되지 않았다. SWAN의 LDL이 계산식 값이라 TG 400 이상이 빠진 것으로 추정하나, 코드북 확인이 필요하다.
- 국건영 2021~2024에서 모델 대상 조건에 맞는 42~53세 여성 2,080명 중 TG 400 이상은 17명(0.8%)이다.
- **한계:** 0.8%는 전체 대상자 기준이다. TG를 모르는 사용자 집단에서도 같은 비율이라고 보장할 수 없다.
- TG 수치를 모델 개선에 쓰는 것은 현재 수집 목적과 분리한다. 계획이 확정되면 **별도 선택 동의**를 받은 뒤부터 수집한다.

## 2. LDL은 예측할 수 없다

"LDL이 없는 사용자에게 다른 정보로 LDL이나 위험을 추정할 수 있는가"를 세 가지로 확인했다.

| 시도 | 데이터 | 결과 |
|---|---|---|
| 나이·키·체중·허리둘레·혈압 → LDL 수치 | 국건영 여성 40~59세 3,644명 | R² 0.065 (비선형 0.047) |
| BMI → LDL 수치 | 국건영 여성 40~59세 2,932명 | 상관 0.115, R² 0.013 |
| LDL 없이 5년 내 고LDL 예측 | SWAN 학습 세트 1,441명 | 아래 표 |

**입력 구성별 AUROC (학습 세트 5겹 교차검증, 10회 반복)**

| 입력 구성 | AUROC |
|---|---|
| C3 8변수 (현재 모델) | 0.806 |
| LDL 단독 | 0.802 |
| 총콜레스테롤 단독 | 0.787 |
| C3에서 LDL만 제외 (7변수) | 0.625 |
| LDL 없이 가능한 변수 전부 (11개) | 0.627 |

**예측 위험 5분위별 실제 발생률**

| 위험 그룹 | LDL 있음 | LDL 없음 |
|---|---|---|
| 가장 낮은 20% | 2.8% | 8.0% |
| 두 번째 | 4.9% | 16.3% |
| 세 번째 | 11.5% | 16.0% |
| 네 번째 | 21.5% | 20.5% |
| 가장 높은 20% | 47.9% | 27.8% |

LDL이 없으면 가장 낮은 그룹에서도 8%가 고LDL이 된다. **잘못된 안심을 줄 수 있으므로 LDL이 없으면 예측하지 않는다.** 현재 A 분기 설계를 데이터가 뒷받침한다.

**출발 LDL 구간별 5년 발생률 (모델 1 코호트 2,059명)**

| 출발 LDL (mg/dL) | 인원 | 5년 발생률 |
|---|---|---|
| 100 미만 | 713 | 3.6% |
| 100~114 | 427 | 6.8% |
| 115~129 | 418 | 20.6% |
| 130~144 | 304 | 36.2% |
| 145~159 | 197 | 57.4% |

## 3. 허리둘레 예측 모델 (멘토 과제)

문진에서 허리둘레를 직접 받지 않고 나이·키·체중으로 채울 수 있는지 확인했다.

### 3.1 설계

| 항목 | 내용 |
|---|---|
| 데이터 | 국건영 2021~2024 여성 42~53세, 허리둘레·키·체중 측정자 2,564명 |
| 개발 | 2021~2023 (1,888명), 5겹 교차검증 10회 반복 |
| 시간적 검증 | 2024 (676명). 모델을 정한 뒤 한 번만 평가 |
| 외부 확인 | SWAN 동아시아계 기저 523명 |
| 전처리 | 결측 제거. 조사 가중치 미적용 |

### 3.2 후보 비교 (개발 세트 교차검증)

| 모델 | R² | RMSE (cm) |
|---|---|---|
| 평균값 (기준선) | −0.004 | 9.93 |
| 체중 | 0.808 | 4.33 |
| 나이 + BMI | 0.843 | 3.92 |
| **나이 + 키 + 체중, 선형 (선택)** | **0.863** | **3.67** |
| 나이 + 키 + 체중, 비선형 | 0.834 | 4.02 |

`허리둘레 = 84.1 + 0.156×나이 − 0.426×키 + 0.927×체중` (adj. R² 0.864, VIF 1.04~1.15)

### 3.3 검증 결과

| 지표 | 2024 시간적 검증 (95% CI) | SWAN 동아시아계 |
|---|---|---|
| R² | 0.869 (0.844~0.891) | 0.811 |
| RMSE | 3.78 cm (3.55~4.04) | 4.14 cm |
| 평균 편향 | +0.65 cm (0.37~0.94) | +2.0 cm |
| ±5 cm 이내 | 82.8% (79.7~85.7) | 77.8% |

Bland–Altman 일치 한계는 −6.7~+8.0 cm이고, 복부비만(85 cm 이상) 판정의 민감도는 85.3%, 특이도는 95.1%다. BMI 30 이상에서 RMSE가 5.6 cm로 커진다.

### 3.4 모델 1에 미치는 영향 (학습 세트 교차검증 20회)

| 허리둘레 입력 | AUROC |
|---|---|
| 실제값 | 0.805 |
| 예측값으로 대체 | 0.804 |
| BMI로 대체 | 0.804 |
| 제외 | 0.805 |

허리둘레는 모델 성능에 영향이 없다. **직접 받을지, 예측값으로 채울지, 뺄지는 문진 부담 기준으로 정하면 된다(6장).** 예측값을 쓸 때는 "추정" 표시가 필요하다.

## 4. 한국인 적용성 점검

### 4.1 분포 비교

SWAN 모델 1 코호트와 국건영 2021~2024 여성 42~53세(지질약 미복용, 직접측정 LDL 160 미만)를 비교했다.

| | SWAN 코호트 (2,059명) | 국건영 (1,503명) | SWAN 동아시아계 (523명) |
|---|---|---|---|
| 나이 | 45.9 ± 2.7 | 47.4 ± 3.5 | 46.1 |
| 허리둘레 (cm) | 84.9 ± 15.9 | 77.8 ± 9.8 | 75.3 |
| BMI | 27.7 | 23.1 | — |
| LDL (mg/dL) | 110.1 | 116.0 | — |
| 흡연율 | 14.0% | 5.7% | — |

체형과 흡연율이 다르다. SWAN 동아시아계의 체형은 한국 여성과 비슷하다.

### 4.2 동아시아계 분리 점검

동아시아계(중국계·일본계)를 학습에서 빼고 나머지로 모델을 만든 뒤 동아시아계에 적용했다.

| 항목 | 값 |
|---|---|
| 학습 | 동아시아계 제외 1,649명 (발생 18.4%) |
| 점검 | 동아시아계 410명 (발생 61건, 14.9%) |
| AUROC | 0.846 (95% CI 0.789~0.896) |
| 예측 평균 / 실제 발생률 | 14.8% / 14.9% |
| 4분위 예측 | 1.8% · 5.2% · 13.8% · 38.1% |
| 4분위 실제 | 1.9% · 2.9% · 9.8% · 44.7% |

**이 점검은 독립 검증이 아니다.** 배포 모델과 다른 모델(동아시아계 제외 학습)을 평가한 것이고, 대상자에 홀드아웃 구성원이 포함된다. 모델 선택에는 쓰지 않았다. 동아시아계 미국인은 한국인과 생활환경이 다르고, 61건이라 신뢰구간이 넓다.

### 4.3 국건영 가상 코호트 점검

국건영은 추적 자료가 없어 실제 발생률로 채점할 수 없다. 대신 나이별 유병률(LDL 160 이상 또는 이상지질혈증 약 매일 복용, 조사 가중치 적용, 3세 이동평균)의 차이로 5년 발생률을 추정했다: `(P(나이+5) − P(나이)) / (1 − P(나이))`. 직접측정 LDL이 없으면 Friedewald 계산값(TG 400 미만)을 썼다.

국건영 여성 1,950명에 모델 1을 적용한 예측 평균과 비교했다. 국건영에 없는 폐경 단계·안면홍조·야간발한은 학습 세트 중앙값으로 채웠다.

| 나이 | 모델 예측 평균 | 한국 추정 발생률 | SWAN 실측 | 추정/예측 |
|---|---|---|---|---|
| 42~43세 | 14.3% | 5.9% | 12.9% | 0.41 |
| 44~45세 | 16.4% | 9.3% | 14.3% | 0.57 |
| 46~47세 | 17.9% | 14.4% | 19.4% | 0.80 |
| 48~49세 | 23.6% | 20.3% | 24.5% | 0.86 |
| 50~51세 | 25.2% | 24.7% | 20.0% | 0.98 |

- **46세 이상에서는 예측과 추정 발생률이 가깝다.**
- **40대 초반에서는 모델이 2배 넘게 과대평가할 가능성이 있다.**
- 이 추정은 **모델 적합성 점검에만 쓰고, 모델을 재보정하는 데 쓰지 않았다.**

**한계:** 가상 코호트는 세대 차이가 없다고 가정한다. SWAN(1996~2006)과 국건영(2021~2024)은 시대가 달라 약 처방 관행이 다르다. 나이 한 살 단위 추정치는 불안정하다. 따라서 "과대평가한다"가 아니라 "과대평가 가능성이 있다"로 해석한다.

### 4.4 결론

| 질문 | 답 |
|---|---|
| 순위(등급)를 한국인에게 써도 되는가 | 동아시아계에서 변별력이 유지됐다. 해외 모델 이식 사례(Framingham의 한국·중국 적용)와 같은 방향이다 |
| 확률(%)을 그대로 보여줘도 되는가 | 40대 초반 과대평가 가능성이 있다. **MVP 확률 미제공 결정을 유지할 근거다** |
| 근본 해결 | 한국 종단 코호트(KoGES, 건보공단)로 재보정·외부 검증. 배포 후 과제 |

## 5. 다음 버전(v2) 후보 변수

학습 세트 교차검증(5겹, 10~20회 반복)으로 확인했다. **홀드아웃이 소진됐으므로 MVP 모델은 바꾸지 않는다.** v2는 새 검증 데이터가 있어야 평가할 수 있다.

| 구성 | AUROC |
|---|---|
| C3 8변수 (현재) | 0.806 |
| C3 + HDL | 0.809 |
| C3 + 중성지방 | 0.817 |
| LDL + 중성지방 (2변수) | 0.818 |

`LDL + 중성지방`에 변수를 하나씩 더했을 때의 변화다(반복 간 표준편차 약 0.002).

| 추가 변수 | 변화 | 판단 |
|---|---|---|
| 공복혈당 | +0.004 | 후보. 검진 결과지에 있다 |
| 수축기 혈압 | +0.002 | 후보. 검진 결과지에 있다 |
| 소득 | +0.004 | **제외.** 결과 정의에 '약 복용 시작'이 있어 의료 이용 차이를 반영할 가능성이 크다 |
| 나이·허리둘레·BMI·흡연·운동·폐경 단계·증상 | 0.001 이하 | 추가 효과 없음 |

중성지방은 공복 여부에 따라 달라지므로 v2에서 쓸 때는 공복 검사값인지 확인이 필요하다. 1.2절 결정에 따라 TG 수치는 선택 동의 이후부터 쌓인다.

### 6.1 챌린지 설계 변경 제안서(11/27, 은지님)와 맞춰야 할 점

같은 날 공유된 챌린지 설계 변경 제안서를 모델 관점에서 읽고, 현재 모델과 다른 부분을 적는다. 결정은 팀 회의에서 한다.

| 제안서 내용 | 현재 모델 기준 | 필요한 결정 |
|---|---|---|
| 모델 입력 5개(나이·성별·체중·키·LDL) | 검증한 모델은 **C3 8변수**(나이, 허리둘레, 폐경 단계, 안면홍조, 야간발한, 흡연, 수축기 혈압, LDL)다. 성별은 입력이 아니라 대상 조건이다 | 나머지 변수를 문진으로 받을지, 입력을 줄인 새 모델을 만들지. 새 모델은 홀드아웃이 소진돼 같은 방식으로 검증할 수 없다(5장) |
| 진단자·LDL 160 이상인 사람도 예측 | 모델은 **LDL 160 미만, 지질약 미복용자만** 학습했다. 그 밖은 학습 범위 밖이다. LDL이 입력이므로 "LDL 높은 사람을 높게 예측"하는 것은 성능 근거가 되지 않는다 | 이 집단은 예측 없이 안내 문구만 보여주는 방식 검토 |
| A 모델(LDL 없음)의 확률 산출 | LDL 없이는 AUROC 0.63이고 낮은 그룹에서도 8%가 발생한다(2장) | A 분기는 예측 없이 검진 안내 유지 권고 |
| 위험도 구간 기준값은 모델 담당이 정함 | 미정 | 4.3절의 40대 초반 과대평가 가능성을 반영해 정한다 |
| 설치형 앱 전제, 건강 앱 연동 | 과제 안내문은 "웹 서비스"다 | 서비스 형태 확인 |
| 검진 당시 나이와 현재 나이 | 모델은 **LDL을 잰 시점의 나이**로 학습했다 | 검진일 기준 나이를 쓰고, 예측 기간도 검진일부터 센다 |
| 가정혈압 평균을 모델 입력으로 | SWAN 혈압은 방문 시 측정값이다 | 매핑표(DR-014)에서 정의 확인 |

## 7. 참고 분석 — 폐경과 LDL ("왜 관리해야 하는가")

SWAN에서 같은 여성의 단계별 LDL을 비교했다(지질약·호르몬제 사용 방문 제외).

| 폐경 전 대비 | 인원 | LDL 변화 (mg/dL) | LDL 160 이상 비율 |
|---|---|---|---|
| 이행기 초기 | 1,111 | +2.7 | 6.8% → 6.8% |
| 이행기 후기 | 388 | +11.4 | 7.0% → 13.9% |
| 폐경 후 | 469 | +14.3 | 6.4% → 16.4% |

나이 효과를 개인 내 회귀로 보정하면(3,206명, 13,080회 방문) 이행기 후기 +5.1(95% CI 3.3~7.0), 폐경 후 +5.6(3.6~7.6)이다. 결과 안내의 설명 근거로 쓸 수 있다. 문구는 기획 담당이 정한다.

## 9. 범위 밖으로 둔 탐색

11/27에 검토했으나 **채택하지 않았다.** 고LDL 예측 하나를 끝까지 검증하는 쪽을 택했다.

| 탐색 | 확인한 것 | 채택하지 않은 이유 |
|---|---|---|
| 골다공증 선별 | 국건영 2008~2011 골밀도 자료에서 나이·체중·폐경 정보로 선별 가능함을 확인 | 주제 범위 확대. 선별이지 발생 예측이 아님 |
| 심혈관질환 예측 | 한국형 공개 모델이 있으나 혈액검사 필요 | 타깃 연령에서 대부분 저위험. 설명 근거로만 활용 |
| 웨어러블 연동 | 통합 API는 모바일 SDK 필요 | 예측 모델을 학습할 데이터가 없음. 연동 여부는 서비스 형태(웹·앱) 결정에 따름 |

**재현:** 이 문서의 분석 스크립트(국건영 비교, 허리둘레 모델, 적용성 점검)는 경로 정리 후 후속 PR로 올린다. 그때까지 2~5장 수치는 스크립트 없이 기록만 있는 상태다.
