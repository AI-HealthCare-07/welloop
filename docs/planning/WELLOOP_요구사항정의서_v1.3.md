- 기준일: 2026-11-17 (11/17 중간회의 결정 반영)
- 구성: 기능 36개 / 비기능 17개

- 이 문서를 바꿀 때는 이 파일을 수정해서 PR로 올려요.

## 서비스 구조 요약

1. **건강 문진** (4단계): 기본 건강정보 → 생활습관 → 건강 위험요인 → 개인 맞춤 설정
2. **건강 상태 평가** (질환마다 분기): 미진단 = AI 위험 예측 / 기진단 = 생활습관 관리 평가
3. **맞춤 생활습관 추천**: 식습관 · 신체활동 · 수면·휴식 · 금연·절주
4. **실천 및 변화 관리**: 챌린지 → 체크인·기록 → 대시보드 → 주기적 재평가

- 갱년기는 여성에게 적용하는 개인화 조건이에요.
- 함께 관리 그룹(가족 기능)은 핵심 루프를 만든 다음에 개발해요.
