- **md 한 파일 · 6구역**으로 레포에 올렸어요 (PR #7, `docs/planning/WELLOOP_API명세서_v0.1.md`).

- 규칙: `/api/v1/`, 필드는 snake_case(ERD 컬럼명과 동일), 에러는 코드와 이유를 함께, JWT 인증

### 01 구역 ERD 대조 결과 (엄태은)
- 공유 범위는 NFR-017 기준 3항목(상태 칩·챌린지·추이)만 사용해요. 위험도·수치·기분 공유는 제외했어요.
- 알림은 `consents`(NOTIFICATION), 큰 글씨는 `users.font_size`(NORMAL/BIG)로 맞췄어요.
- 추가한 API: 토큰 재발급, 동의 내역 조회, 그룹 요약 보기, 고른 문구 보내기

### RAG 특강에서 프로젝트에 가져갈 것
- AI 코치 = LLM + 의료 안전 하네스. 숫자는 코드로 계산하고, LLM은 말투만 맡아요.
- 환각은 "없음"이 아니라 "완화"라고 표현해요 (근거 검색, 근거 없으면 답 보류, 서버 금지어·수치 검사).
- 권고 문서 검색: 메타데이터(질환·카테고리) 필터 + 하이브리드 검색 + 재순위 + 질문 재작성(일상어 → 의학 용어)
- 평가: 베이스라인부터 기능 하나씩 추가하며 점수를 기록해요 (RAGAS).
- 관측성(Langfuse): 토큰·비용·지연·도구 호출 추적
- 사용자 건강 기록은 LLM이 SQL을 직접 쓰지 않고, 백엔드의 정해진 API로만 조회해요.
- 특강 정리본: 팀장 공유 링크
