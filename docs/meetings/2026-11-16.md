| 고령층 | 65세 이상 로그인 시 큰 글씨 모드 자동 적용 |
| 안전 원칙 | 진단·처방 X, 생활습관 관리 보조. 위험 신호 시 병원·전문 상담 안내 |

### 서비스 흐름 (Loop)

```
문진표 입력 → AI 위험도 예측 → 맞춤 예방 플랜(흡연·음주·식습관·수면 모듈)
→ 데일리 챌린지(체크인 + 호흡·스트레칭) → 추적 대시보드 → 위험도 재계산 ↺
```

### MVP 범위

- 회원가입·로그인(JWT), 문진표, 3대 질환 위험도 예측
- 예방 플랜 모듈 1개 (흡연 또는 식습관)
- 데일리 챌린지 + 수면·기분 체크인, 추적 대시보드
- AI 코치 말투(LLM) + 아첨 방지·안전 규칙
- 65세 이상 큰 글씨 모드, 호흡·스트레칭 루틴 3~5개
