## 1. 결정 사항

### 서비스 · 타깃
- 서비스 이름에는 나이를 넣지 않아요 (예: "만성질환 예측·케어"). 이름은 추후 확정해요.
- 타깃은 중장년(40~64세)이지만, 다른 나이도 사용할 수 있게 열어 둬요.
- 갱년기는 **여성 한정**으로 해요.
- 타이틀은 "만성질환"으로 넓히고, **예측은 3대 질환(고혈압·당뇨·이상지질혈증)을 유지**해요.

### 서비스 구조 (시윤 구조안 확정)
1. **건강 문진** (4단계): 기본 건강정보 → 생활습관 → 건강 위험요인 → 개인 맞춤 설정
2. **건강 상태 평가** (질환마다 분기)
   - 미진단 질환: AI 건강 위험 예측. 의학적 진단이 아니라 건강관리 참고 지표예요.
   - 기진단 질환: 재예측하지 않고 생활습관 관리 평가를 해요. 실천 정도와 기록 추이를 보여 주고, 기준을 넘으면 진료를 권해요.
3. **맞춤 생활습관 추천**: 식습관 / 신체활동 / 수면·휴식 / 금연·절주
4. **실천 및 변화 관리**: 챌린지 → 체크인·기록 → 대시보드 → 주기적 재평가
- 질환별 "프로그램"을 고르는 단계는 없앴어요. 갱년기는 개인화 조건이에요. 해당 여성에게 증상 기록과 변화 추적 기능을 제공해요.

### MVP 범위 · 숫자
- MVP 범위는 지금 확정하지 않아요. 프로토타입을 만들어 보며 뺄 것과 키울 것을 정해요.
- 임시 숫자(잠금 10분, 상담 안내 7일 중 5일, max_tokens 512, 위험도 경계값 등)는 개발하며 조정해요.

### 관리자 기능
- 운영 확인: 유저 증가 추이, LLM 사용량
- 위험도 경계값 설정
- 위험 키워드 추가·삭제 (LLM이 아닌 서버 규칙)
- 고정 데이터(챌린지 등) 등록·수정

### 함께 관리 그룹 (가족 기능 · 은지 화면 참고)
- 토스 커플 통장처럼 두 사람이 모두 가입하고, 서로 동의해서 그룹을 연결해요. 관계는 부부·커플·부모·자녀·가족 중에서 고르고, 그룹 이름은 직접 지정해요.
- 상대에게는 **본인이 허락한 상태 요약(칩) + "이렇게 도와주세요" 한 줄**만 앱 화면으로 보여요.
- 문자·카톡 알림은 비용 때문에 쓰지 않아요.
- 말투는 가볍게 해요 (예: "어깨 한번 주물러 주세요"). "당장 병원 가세요" 같은 표현은 서버에서 막아요. 말투는 보내는 사람이 예시 중에서 골라요.
- LLM이 전달할 문구 후보를 만들고, **본인이 허락한 것만** 골라서 보내요 (명석 제안).
- 원칙
  - 감정 메모·대화 원문·위험 신호는 공유하지 않고 LLM에도 보내지 않아요.
  - 성인끼리만 연결해요.
  - 핵심 루프를 만든 다음에 개발해요.

### 데이터 · 모델 (도엽)
- 국민건강영양조사 2021~2024 (45세 이상 검진 완료자 약 1.5만 명)
- 이미 진단받은 비율이 높아서(고혈압 83%, 당뇨 77%) **미진단자만으로 학습**해요. 정답은 수치 기준 초과예요. 전체 학습 모델과의 비교는 실험 기록으로 남겨요.
- 짠 음식·단 음식·정제 탄수화물, 수면 불편, 금연 의향, 운동 제한은 데이터에 문항이 없어서 **추천용으로만** 써요.
- 재계산 규칙
  - 체중·허리둘레: 최신값 자동 반영
  - 수면: 2주 평균
  - 흡연·음주·활동·식습관: 2주마다 1분 재문진
  - 하루 최대 1회 계산
